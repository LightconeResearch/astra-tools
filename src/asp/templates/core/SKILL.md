# ASP Analysis Skill

Help users work with the Agentic Science Protocol (ASP) - a declarative specification format for scientific analyses.

## Workflow

**ASP is the source of truth. Always follow this order:**

1. **Design** → Build `asp.yaml`
2. **Generate** → `asp workflow generate` creates CWL from ASP
3. **Implement** → Write Python scripts in `scripts/`
4. **Run** → Execute via CWL workflow (NEVER generate results without workflow)

## CLI Commands

```bash
# Design phase
asp init <directory>              # Create new analysis project
asp validate asp.yaml             # Validate specification
asp info                          # Show analysis summary
asp universe generate -n baseline # Generate universe from defaults
asp viz                           # Visualize decision space

# Generate phase
asp workflow generate             # Generate CWL skeleton from ASP

# Run phase
asp workflow validate --cwl main.cwl    # Validate CWL mapping
asp workflow run universes/x.yaml --cwl main.cwl -o results/  # Run workflow
```

## Project Structure

```
my-analysis/
├── asp.yaml           # Specification (WHAT to compute) - SOURCE OF TRUTH
├── universes/         # Decision selections
│   └── baseline.yaml
├── workflows/         # CWL files ONLY (.cwl) - generated from ASP
│   └── main.cwl
├── scripts/           # Python scripts ONLY (.py)
│   └── main.py
└── results/           # Outputs (generated by workflow)
```

**Key rules**:
- ASP defines WHAT, CWL is derived from ASP
- `.cwl` files go in `workflows/`
- `.py` files go in `scripts/`
- Results MUST be generated via CWL workflow

## Available Agents

- **asp** - Design and execute ASP analyses. Handles both spec creation and workflow execution.

Invoke with: `/agents/asp`

## Creating an Analysis

1. `asp init my-analysis --agent claude-code`
2. Edit `asp.yaml` to define inputs, outputs, decisions
3. Validate with `asp validate asp.yaml`
4. Generate CWL: `asp workflow generate`
5. Implement scripts in `scripts/`
6. Run: `asp workflow run universes/baseline.yaml --cwl workflows/main.cwl`

## Extracting Insights from Papers

```yaml
insights:
  finding_name:
    claim: "One sentence stating what we learned"
    source:
      doi: "10.1234/paper-doi"
    evidence:
      - figure: "Figure 3a"
        caption: "What it shows"
```

Reference in decisions:
```yaml
decisions:
  method_choice:
    options:
      method_a:
        evidence:
          - insight: finding_name
```

## CWL Parameter Naming Convention

ASP decisions map to CWL parameters automatically:
- Simple value → `{decision_id}`
- Dict value `{a: x, b: y}` → `{decision_id}_a`, `{decision_id}_b`

`asp workflow generate` creates these mappings for you.
