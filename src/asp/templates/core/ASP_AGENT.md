# ASP Agent

Help users design and execute ASP (Agentic Science Protocol) analyses.

## Project Structure

```
my-analysis/
├── asp.yaml           # Specification (WHAT to compute) - SOURCE OF TRUTH
├── universes/         # Decision selections
│   └── baseline.yaml
├── workflows/         # CWL files ONLY (.cwl) - generated from asp.yaml
│   └── main.cwl
├── scripts/           # Python scripts ONLY (.py)
│   └── main.py
└── results/           # Outputs (generated by workflow)
```

## Workflow

**ASP is the source of truth. Always follow this order:**

1. **Design** → Build `asp.yaml`
2. **Generate** → Create CWL skeleton from ASP
3. **Implement** → Write Python scripts
4. **Run** → Execute via CWL workflow (NEVER generate results without workflow)

---

## Phase 1: Design (Interactive)

Help the user create `asp.yaml`:

1. **Understand the problem**: What research question are they answering?
2. **Identify inputs**: What data do they have?
3. **Define outputs**: What results do they need?
4. **Map decisions**: What methodological choices exist?

Write `asp.yaml` incrementally. Validate with `asp validate asp.yaml`.

When complete, generate a baseline universe:
```bash
asp universe generate -n baseline
```

---

## Phase 2: Generate CWL (Automatic)

Once `asp.yaml` is ready, generate the CWL workflow skeleton:

```bash
asp workflow generate
```

This creates `workflows/main.cwl` with:
- Inputs for each ASP input and decision
- Outputs for each ASP output
- Placeholder baseCommand

---

## Phase 3: Implement (Autonomous)

Write Python scripts in `scripts/` that the CWL workflow calls:

```python
# scripts/main.py
import argparse
import json

parser = argparse.ArgumentParser()
# Arguments match CWL inputs (auto-generated from ASP)
parser.add_argument("--primary-data", required=True)
parser.add_argument("--preprocessing", required=True)
parser.add_argument("--model", required=True)
args = parser.parse_args()

# Your implementation here
result = {"accuracy": 0.95}

# Write outputs (must match CWL output glob patterns)
with open("accuracy.json", "w") as f:
    json.dump(result, f)
```

Then update `workflows/main.cwl`:
- Set correct `baseCommand`
- Adjust output glob patterns to match your script

---

## Phase 4: Run (Always via Workflow)

**NEVER generate results directly. Always run through the CWL workflow:**

```bash
asp workflow run universes/baseline.yaml --cwl workflows/main.cwl -o results/
```

This ensures reproducibility - results are always traceable to a specific universe.

---

## CLI Commands

```bash
# Design phase
asp validate asp.yaml              # Validate specification
asp info                           # Show analysis summary
asp universe generate -n baseline  # Generate universe

# Generate phase
asp workflow generate              # Generate CWL from ASP

# Run phase
asp workflow validate --cwl workflows/main.cwl  # Validate CWL
asp workflow run universes/baseline.yaml --cwl workflows/main.cwl -o results/
```

## Key Principles

1. **ASP is source of truth** - CWL is derived from ASP, not manually created
2. **Always run via workflow** - Never generate results without CWL
3. `.cwl` files in `workflows/`, `.py` files in `scripts/`
4. Work autonomously - implement without excessive asking
5. Report results clearly when done
